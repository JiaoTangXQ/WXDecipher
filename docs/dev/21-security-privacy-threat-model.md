# 21 · 安全与隐私威胁模型

工具处理高度敏感的个人聊天数据，安全与隐私是一等需求。本册记录资产、边界、威胁与缓解，以及合规约束。

## 1. 资产（要保护什么）

| 资产 | 敏感度 | 位置 |
|---|---|---|
| 微信主密钥 / 图片密钥 | 极高 | 内存（临时）→ Keychain |
| 原始加密数据库 | 高 | 微信容器（只读） |
| 解密后的明文库 | 极高 | 工具数据目录 `decrypted/` |
| 媒体解码缓存 | 高 | `.media_cache/` |
| 聊天正文/联系人 | 极高 | 明文库/内存 |
| MCP token | 中 | 生成配置文件 |

## 2. 信任边界

```text
[微信进程内存] ──(lldb,一次性,需特权)──▶ [本工具进程]
[微信容器(只读)] ──────────────────────▶ [本工具进程] ──▶ [工具数据目录(读写)]
[本工具进程] ──(仅127.0.0.1+token)──▶ [本机 AI 客户端]
[表情CDN] ◀──(可选,按消息自带地址)── [本工具进程]
```

- 强边界：原始微信目录（只读）↔ 工具数据目录（读写）。
- 网络边界：默认不出网；唯一例外是表情缩略图按消息自带 CDN 地址下载（可关闭）。
- 本机边界：MCP 只绑回环，不监听局域网。

## 3. 威胁与缓解

| 威胁 | 场景 | 缓解 |
|---|---|---|
| 密钥泄露到日志/输出 | 调试日志、异常、MCP 返回 | 全链路脱敏，只出指纹；`redact()` 兜底；单测校验 |
| 明文库被他人读取 | 工具数据目录被拷走 | 目录在用户主目录（受账户权限保护）；README 提示不要分享 `decrypted/`；可选后续加"用完清理"入口 |
| MCP 被本机其它进程滥用 | 回环端口被探测 | 随机端口 + 每次随机 Bearer token；token 只写用户可读配置；关程序即失效 |
| MCP 把整库塞给 AI | 大返回 | 硬上限 `max_bytes`/`max_body_length`；大数据落文件 + Resource |
| 误写/破坏原始微信数据 | 解密/媒体流程 bug | 只读打开；`assert_within_workspace` 守卫；只读性回归测试 |
| 关 SIP 后系统长期暴露 | 用户忘记开回 | 向导强提示抓完 `csrutil enable`；检测到 SIP 关闭时在 UI 常驻提醒 |
| 重签名破坏微信 | 高级备选方案 | 仅文档，不默认；提示对副本操作、风险自负 |
| 恶意"密钥"输入 | 手动导入 | 长度/格式校验 + 页 HMAC 校验，不匹配拒绝 |
| CDN 下载被用于追踪/注入 | 表情预览联网 | 仅按消息自带地址、仅图片、写受限缓存；提供全局关闭联网开关 |
| 供应链 | 依赖被投毒 | 锁定依赖来源；最小依赖面；`.app` 自包含 |

## 4. 隐私原则

- **数据最小化**：只解密用户选择的账号；媒体按需解码。
- **本地优先**：不上传聊天数据到任何远程；无遥测。
- **可清理**：删除 `~/Library/Application Support/WeChatDecryptor/` 即清除全部解密副本、缓存、MCP 配置；Keychain 项可单独删除。
- **透明**：UI/日志显示正在做什么（发现、解密、取密钥、联网下载），敏感动作需确认。

## 5. 合规约束

- 仅用于对**使用者本人可合法访问的本地数据**进行解密查看。
- 首次取密钥涉及调试本机微信进程与临时关闭 SIP，需在符合当地法律与微信用户协议前提下由用户本人操作。
- 分发物 README 必含：用途边界、免责声明、"不要分享密钥/解密库/配置"的提示。
- 不提供绕过他人设备/账号保护的能力，不针对非本人数据。

## 6. 安全测试要点（并入 13）

- 脱敏回归：grep 全部日志/导出无 64 hex 密钥串、无聊天正文。
- 只读回归：全流程后原始 `db_storage` 文件未被修改。
- MCP：无 token/错误 token 拒绝；非回环访问不可达；超限被拦截。
- 清理：删除数据目录后无残留明文。
